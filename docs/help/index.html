SYNAPSE help

Describe a task.Inspect the nodes.Keep creative control.

This help is for someone who knows Houdini and is new to SYNAPSE. Use a scratch scene for your first run.

First session

Four steps

  1. Open the pane

    In Houdini, choose New Pane Tab → Synapse.

    The pane opens with a short welcome, and the prompt below it.

  2. Choose a model

    Click Connect models, below the prompt. Pick a service and a model, and add its key if it needs one.

    Under Task needs, select Build and edit networks. Then click Check connection, and Use this model.

  3. Start the bridge

    Click Connect, at the top. It starts the local bridge that lets tools reach Houdini.

  4. Check the setup

    Click Doctor, at the top. It checks this installation without a model request, and without touching your scene.

If you use Ollama, start its service before step 2.

Opening it again

The Synapse shelf

The Synapse shelf has a Synapse button. It brings back an open Synapse tab, or docks a new one beside the Network Editor.

Save your desktop once, so the docked tab is there next time: Windows → Desktop → Save Current Desktop As.

First build

Three steps

  1. Ask for a box

    Type this in the prompt and press Enter.

    make a box
  2. Read the network

    Look at the network, not the conversation. The nodes are the result. The conversation is only how you asked.

  3. Try a change

    Change a parameter on the new node. Then try Houdini's Undo, and Redo.

The receipt

At the end of a reply

When a turn changes your scene, its reply ends with a receipt. The receipt shows a count, such as 2 CHANGES, and a ← REVERT control.

REVERT takes back only what SYNAPSE did in that turn. It never undoes an edit of yours.

If anything has changed since, even the selection, REVERT refuses and changes nothing. Houdini's own Undo still works.

Undo

Before a large request

Save first. Undo reverses the scene, not the disk. Files, caches and renders stay written.

Undo covers one recorded operation. It does not reverse a whole conversation.

A failed build can leave partial nodes behind. Look at the network and undo them yourself.

Ask→

Say what you want.Then read the network.

SYNAPSE reads your scene through Houdini itself. It can still be wrong, so the network is the proof.

How to ask

In the prompt

Describe the result, not the node names.

“Scatter points on the ground and instance the rocks” works better than a list of operators. SYNAPSE knows Houdini. It needs to know what you intend.

Ask for a large job in stages. You will catch a wrong turn three nodes in, not thirty.

Reading the result

After every reply

The summary is a claim. The nodes are the evidence.

A model can be confidently wrong. It can build something plausible and describe it as what you asked for.

Checking the network takes five seconds. It is the one habit that makes this tool safe.

What the model may do

In this panel

In the panel, the model works only through permitted tools.

The normal panel worker blocks node deletion, arbitrary Python and VEX, rendering, exporting and PDG cooking.

Tool policy and boundaries

What leaves your machine

You are asked first

Before a task sends your work to a model service, the panel asks: Allow this model connection?

That service can receive your prompts, the conversation, scene context, recalled memory and tool results.

You can allow one task, or the whole session. A session permission lasts until Houdini exits.

Revoke session model permissions, in the lightning menu, takes it back.

Saved memory stays on this computer. What is recalled from it may be sent.

Verified recipes

Built and checked on 22.0.400

Some requests have a recipe that was built and checked on Houdini 22.0.400.

The first one that reads the scene for you is Scatter Instances, on an imported Gaussian-splat world.

Scatter rocks along the cobblestone lane.

SYNAPSE reads the scene before it builds.

It looks for four things: the camera, the world, the world's collider, and the place in the chain where the new nodes go. It tells you where it read each one.

If anything is missing or ambiguous, the answer is UNKNOWN and nothing is built.

If everything is known, it builds with the recipe's own values. An older note in memory cannot change them.

Memory

Scene and project notes

Ask in plain words what SYNAPSE remembers about this scene.

It reads the scene's saved notes first. It tells you the answer is recalled, not measured again.

Only what you ask it to remember is stored.

A recalled note is advice. It does not authorize a change to your scene.

Models

You choose

SYNAPSE works with Claude, Gemini, NVIDIA Nemotron, Ollama and your own compatible endpoint. Tool support varies between them.

A local Ollama model needs no key.

A cloud or relay model can send your work elsewhere, even through a local service. Check the model and the destination, not only the address.

Check connection reads the service's model list. It does not test that the model can generate or build.

JEV

Optional

JEV is optional assistance from TypeSafe. It can rank actions for a selected network, or measure routing. Your generation model stays selected.

Add a key in Connect models, under JEV / TypeSafe key setup, with Save session key.

Saving a key keeps it in memory until Houdini closes. It does not turn JEV on, verify the key or grant permission.

The panel→

Every control,from top to bottom.

Choose a control on the map to find its line. Bold words in a sentence are controls you can click.

Top

Model name

Top right

This is the model that will answer. Click it to choose another, or to open Connect models.

Until you choose one, it reads Choose a model.

Status line

Under the wordmark

This line says where things stand, in one short sentence.

Examples are Ready, Working on it, Result ready and Not connected.

Read it first when nothing seems to happen.

The line under it names the scene file and the current frame.

Connect

Top row

It starts the local bridge on port 9999, so tools and outside MCP clients can reach Houdini. The bridge does not start by itself.

It is safe to click at any time. It is not the model chooser.

Doctor

Top row

It checks this installation. It sends no model request and changes nothing in your scene.

Each line reads PASS, NEEDS ATTENTION or NOT CHECKED.

A check that did not run is never shown as a pass.

Copy report gives you text to paste into a bug report.

A narrow panel moves this button into the lightning menu.

Lightning menu

The lightning icon, top row

This menu holds the tools and settings you do not need every minute.

Lines divide the menu into four groups. This list follows them, in the same order.

Copies the conversation as text.
Revoke session model permissions
Takes back a permission you gave for the session.
Build HDA…
Turns a working network into a digital asset.
Saved lookdev suggestion…

Looks up a checked lookdev setup.

Use in prompt adds editable text to your draft. It does not send it.

Selected network…
Inspects the nodes you have selected, and can suggest actions.

Opens the command list.

Connects the Houdini documentation, so Solaris work uses real node and parameter names.

Switches the model service.

Emergency halt…

In a narrow panel, the first group also holds Doctor, Saved networks and Updates.

Conversation

Conversation

The middle of the panel

Your requests and the replies appear here. A new panel shows a short welcome instead.

A reply that changed your scene ends with a receipt and a REVERT control.

Prompt

Resize

Above the prompt

Drag it to give the prompt more room. The panel remembers where you left it.

Prompt

The dark field

Type here. Enter sends. Shift + Enter starts a new line.

Type / in an empty prompt to browse commands.

Attach

Inside the prompt, left

It adds an image or a file as context for your next request.

Send

Inside the prompt, right

It sends the prompt. While a task runs, STOP takes its place.

STOP ends the panel's turn. The panel says Stopping… until the current step ends.

An operation already sent to Houdini may still be finishing.

Three rows

Commands

First row

It opens the command list. Ctrl + K does the same, and Esc closes it.

Search by a word you know, or narrow the list with DO and WHERE.

Some commands are answered by the panel itself, with no model. They open parts of the panel, such as the render workspace and the saved networks.

The others send a full sentence to your model. Two examples are Check the scene for problems and Summarize the scene.

Saved networks

First row

It keeps useful Solaris networks on this workstation. No model is involved.

Select sibling nodes, choose Save selection, and name what is worth keeping.

Insert a copy brings one back as a new subnet. File assets are not embedded, and outside wires are not reconnected.

Updates

First row

It lists recent work and connection events for this Houdini session. A number beside the name counts the unread ones.

To follow a render output, a File Cache or a TOP node, select it and choose Watch selected. Watching does not start a cook or a render.

Finished means the source reported that it completed. It does not certify the image or the cache.

Needs attention means SYNAPSE saw the work end and could not confirm the outcome. It does not mean the work failed.

Quiet keeps the history without new alerts.

Location

Second row, left

This cell shows where the current model runs: Local, Cloud, Cloud relay, Remote or Unverified.

Click it to read the evidence behind that word.

World Labs

Second row

It imports a Marble world or a Gaussian .ply file.

A World Labs key lets you import from your account. Local files can be imported without one.

Connect models

Second row, right

This is where you choose the service and the model, and tell SYNAPSE what the task needs from it.

It also shows where your work will go, and it holds the JEV key setup.

Check connection reads the service's model list. Use this model makes it the one that answers.

Identify

Third row · no model

Select one or more nodes first. A short bubble appears beside each one.

Each bubble says what the node does, which parameters you changed, and whether it has an error, a warning or a bypass.

No model runs and nothing leaves your machine. The bubbles are drawn over the editor, so nothing is written to your scene.

Click Identify again to clear them. Each click shows up to 60 bubbles.

You can also send /identify and /identify off.

Spatial

Third row · no model

It reads how the shot's camera moves through the scene, and draws its path in the viewport.

It uses no model, and it is one undo step.

You can also send /spatial.

Render

Third row · no model

It opens the render workspace. The workspace prepares a saved scene, renders with TOPs and keeps your recent jobs.

  1. Save your scene. An unsaved scene cannot be prepared.

  2. Choose Source, Frames and Render profile.

  3. Open Settings to set Width, Height and Samples.

  4. Click Prepare render. If you change a setting afterwards, prepare again.

  5. Click the render button. It names the frame count, such as Render 24 frames.

Recent renders brings an earlier job back.

You can also send /render.

Scroll with the pointer over a label. The wheel changes a number field under it.

Stuck→

Start with the firstthing to try.

Most sessions that feel broken are one line of Doctor output.

No Synapse pane

Restart Houdini. If the pane is still missing, verify the installation.

I cannot find Doctor

A narrow panel moves Doctor into the lightning menu. Open the menu, or make the panel wider.

Nothing happens when I send

Read the status line. If it says Not connected, click Connect.

Then click Doctor and read the lines that need attention.

The model does not answer

Open Connect models and run Check connection on the selected service.

Ollama models are missing

Start Ollama. Then reopen Connect models and run Check connection.

A build is running away

Click STOP. If Houdini keeps cooking, use Cancel cook or Emergency halt… in the lightning menu.

Then inspect the scene.

REVERT refuses

Something changed after that turn, so SYNAPSE will not touch it. Use Houdini's own Undo.

Identify says “Not in the local SideFX library”

Build and connect the SideFX help library, then restart Houdini.

No saved suggestion appears

Read the reason it gives. It needs a checked record, a matching version and project memory.

The text is too small

Open the lightning menu and choose Larger text.

Where does the TypeSafe key go?

Open Connect models, then JEV / TypeSafe key setup. The setup guide walks through it.

Three ways to stop

STOP

In the prompt, while a task runs

It ends the panel's current turn. It does not prove that a cook or a render has stopped.

Cancel cook

Lightning menu

It cancels one cooking node. It is unavailable when SYNAPSE cannot tell which node is cooking.

Emergency halt…

Lightning menu

It cancels cooking TOP networks under /tasks, /obj, /stage and /out, and captures a session report.

Background renders are reported, not stopped.

A turn also stops itself

Three limits

A turn ends after 25 tool rounds, 10 minutes or 3,000,000 input tokens, whichever comes first.

The last line of the reply says which limit it reached. No tool runs after that line.

Still stuck

Report a bug

Run Doctor, choose Copy report, and paste it into a new issue.

Limits→

The honest edgeof what is built.

This is early software with a model inside it. Reading this page can save you an afternoon.

It can be confidently wrong

This is the failure to expect: plausible output, described as if it were correct.

The answer is cheap and it never changes. Read the network, not the summary.

Undo is not a time machine

Save before a large request. Files, caches and renders stay written after an undo.

Treat a big prompt the way you would treat someone else's HDA: save, then run it.

One artist, one machine

SYNAPSE assumes a single artist on a single workstation. In local mode the bridge has no access control.

Do not expose the bridge port on a shared network.

Real reach

SYNAPSE works inside your Houdini session, with your permissions. The panel limits what its model may do.

An outside MCP client has its own setup and different permissions. MCP connection guide

A check is not a test

Check connection reads a list of models. It does not prove a model can build.

Finished in Updates means a source reported completion. It does not certify the image.

Recipes know one scene shape

The Scatter recipe expects a /stage network, one camera, and a Camera node feeding the render settings directly.

Anything else returns UNKNOWN and builds nothing.

What SYNAPSE is for

SYNAPSE is a rope, not an elevator. It gives you reach you have not earned yet, and safety while you earn it. You are still the one climbing.

If it builds things you could not build alone and you learn nothing, it is failing at its job, however good the output looks.
