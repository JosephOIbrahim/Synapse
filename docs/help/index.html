SYNAPSE
help  ·  v5.42.0

Synapse is a rope, not an elevator. It gives you reach you haven't earned yet and safety while you earn it — you're still the one climbing.

Written for someone who knows Houdini and doesn't know Synapse.

First session

Your first prompt

Type plain English, press Enter, watch nodes appear.

Start with something small enough to verify by eye:

make a grid, scatter 500 points on it, copy spheres to the points

When it finishes, look at the network — not the chat. The nodes are the deliverable; the conversation is only how you asked.

Connect the bridge

Nothing happens until the bridge is up. It doesn't start itself.

Press Connect in the panel header. When it reads Bridge ✓ you're live. If it already read that and nothing is happening, the problem is elsewhere — check the status line under the wordmark.

Install order

The installer is step two, not step one.

Clone or unpack the repository first, then run the installer from inside it. Running the installer against nothing is the most common first-run failure.

Pace

The three profiles

Curious, Expert, ML — how much is explained, not what is possible.

Curious gives you air: readouts you can't act on yet fold away, and the agent narrates each decision in plain language. Expert is full density, no narration, more conversation on screen. ML is Expert with the token and model economics surfaced.

Capability is identical in all three. Switching adds no tools and removes none — and Synapse never switches for you.

How to ask, and how to check what you got.

Synapse runs inside Houdini's own Python, so it isn't guessing at your scene — it's reading it.

Working

How to ask

Describe the result, not the node names.

"Scatter points on the ground plane and instance the rocks" works better than naming operators. Synapse knows Houdini; it needs to know your intent. When a request is large, ask for it in stages — you'll catch a wrong turn three nodes in rather than thirty.

Reading what it did

Trust the network. The summary is a claim; the nodes are evidence.

The agent can be confidently wrong — building something plausible and describing it as if it were what you asked for. Checking the network takes five seconds and is the single habit that makes this tool safe.

The verb rail

EXPLAIN · FIX · OPTIMIZE · BUILD HDA — act on what's selected.

Select a node or a subnetwork, then press a verb. Explain describes what the network does. Fix looks for what's broken. Optimize looks for what's slow. Build HDA turns a working network into a digital asset.

Commands

Type / in the prompt for the command list.

Commands do the things that aren't conversation — session control, mode switches, diagnostics. The list is discoverable; you don't need to memorise it.

Models

Choosing a model

Discovered from your machine, not hardcoded by us.

Synapse reads what's actually available — local models via Ollama, and hosted providers if you've set their API key in the environment. Local models cost nothing and never leave your machine. Larger hosted models handle bigger scene reasoning. Both do the same job at different quality and price.

Panel anatomy and the tools for when things go sideways.

Most sessions that feel broken are one line of doctor output.

Diagnostics

synapse_doctor

Run this first. Always.

It checks connection, licence, environment and model access, and names which one is wrong. If the doctor is clean and the behaviour is still wrong, that's worth reporting — paste its output with the issue.

The panel

Header

Mark, status, Help · Connect · Corpus.

The mark is the status light: an open ring at rest, filling as work completes, closed when done. While work is in flight it's also the halt — the same Stop the rail button fires. Corpus loads the Houdini 21 documentation so scene assembly grounds in real node and parameter names rather than plausible-sounding ones.

CHAT and TOKEN

The conversation, and what it cost.

TOKEN reports usage as the provider reports it. Where a number can't be obtained honestly it shows UNKNOWN — never a zero, never an estimate.

The composer

Drag the divider; it remembers where you left it.

Enter sends. Shift+Enter is a newline. Ctrl+K opens the command palette. The image button attaches references to the next request.

Licences

What your licence allows

Commercial · Indie · Apprentice differ, and it shows up as silence.

Some render paths are unavailable on Indie and Apprentice. If a render appears to do nothing, check the licence before assuming Synapse failed. The README carries the current support matrix.

Early software with an agent inside it. This is the part that saves you an afternoon.

Nothing here is a surprise we're hiding — it's the honest edge of what's built.

Before a large request

Undo is scene-level

Save first. Undo reverses the scene, not the disk.

Files written, caches, and renders stay written after an undo. Treat a big prompt the way you'd treat someone else's HDA: save, then run it.

It can be confidently wrong

Plausible output, described as if correct.

This is the failure mode to expect. The mitigation is cheap and it never changes: read the network, not the summary.

Posture

Single user, localhost

Not hardened for a shared or networked seat.

Synapse assumes one artist on one machine. Access control is off in local mode by design. Don't expose the bridge port on a shared network.

Tools run with real reach

It executes in your session, with your permissions.

The agent can run Python inside Houdini. That's what makes it useful and it's also what makes the save-first habit matter.

The measure

What Synapse is for

Measured by what you can do without it.

If it builds things you couldn't build alone and you learn nothing, it's failing at its job however good the output looks. The gradient runs one way: it builds while you watch, then builds with pauses so you can follow and object, then explains the move and you make it yourself. Explanation rises at your pace. Automation never does.
