# Commands without breaking your flow

Choose **Commands** below the prompt, press **Ctrl+K**, or type `/` into an
empty prompt. Search by a word you know, or use the DO and WHERE filters.

Use the arrow keys and Enter to choose, or click a result. **Escape** closes
the menu and returns to your draft. When nothing matches, **Clear search and
filters** brings back all choices. Each fresh opening starts with all choices.

**/events** opens local work updates. **/saved-recipes** opens the local network
library. These choices do not send a prompt and remain available while a model
task runs. Other tool and recipe choices follow SYNAPSE's existing model and
sharing rules. Selecting a choice keeps the draft you were writing.

Commands, Recipes and Events stay below the composer. Their row wraps when the
panel is narrow. The keyboard hint has its own line so it does not squeeze the
actions. Exact model identity and location remain available in the model controls.

Use the SYNAPSE shelf button to open the panel. It brings back an existing
SYNAPSE tab, or opens a new docked tab when a pane is available. New panels open
SYNAPSE directly, avoiding the width inherited from Houdini's start page. Houdini
hides its Python Panel toolbar for this direct opening. Existing tabs keep their
current layout; the shelf button does not resize them.
