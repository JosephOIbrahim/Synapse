# v5.85.6 — Memory fixes and a truthful embedder report

**A save can no longer duplicate or resurrect a memory record.** The background
flusher could append a line to the memory file just as a save or a clear
replaced that file, which left a duplicate line or brought back a record that
had been cleared. The append and the file replace now take one lock, so they
cannot overlap. Readers do not wait on it.

**Notes for an untitled scene follow the session.** An untitled scene's
`claude/` notes used to go to one folder shared by every launch, while its
memory store lived in that launch's own session folder. The notes now go in the
same session folder as the store. Notes written by earlier versions stay in the
shared folder and are not read by a new launch.

**The memory status report names the embedder that is serving.** The embedder
id is `minilm-l6-v2-d384` whether the ONNX model or the hash fallback produced
a vector, so the id alone cannot tell you which one you have. The report now
carries `embedder_backend`: `onnx`, `hash`, or `unloaded` when no embed has run
yet. Reading it never loads the model. The id is unchanged, so stored data is
untouched. The old docstring claimed the id lets a caller detect a needed
re-embed; it now says it cannot.

**The README is corrected.** It no longer lists the first save of a new scene as
a known issue. v5.85.4 fixed it.

**Also in this release, tests only.** The README receipt now checks the current
two-orange diagrams and a narrower version rule, and runs in the normal suite.
A shared pytest process no longer fails when the Jev tests and the main tests
are collected together.

**Source release for Houdini 22.0.400 / Python 3.13.** No new Windows installer
is included. The older v5.75.2 Setup does not contain these changes. Follow
[source installation](../getting-started/installation.md#source-installation),
then restart Houdini and separate MCP processes to load the updated source.

## Validation and limits

The full `tests/` suite passed locally on Windows with Python 3.14, with the
tests that need a Houdini runtime deselected: 10,278 passed, 457 skipped, 119
deselected, 0 failed. The except ratchet is unchanged at 1,366 broad handlers
and 987 silent ones, and no new broad handler was added. The flusher fix is
pinned by three tests that pause the flusher inside its append; the new notes
and embedder behavior have five tests each. Publication requires all six GitHub
CI jobs to pass on the exact tagged commit, linked in the GitHub release.

Some limits remain. None of these changes was opened in the Houdini GUI; the
checks are unit tests. Vectors already stored from the hash fallback are not
marked, so nothing re-embeds them when the model becomes available. The Moneta
store still cannot be cleared, and nothing in SYNAPSE asks it to.

The inherited [v5.85.5 limits](v5.85.5.md#validation-and-limits) remain.
