# v5.81.0 — Model choice and selected-network assistance

This release improves the native Houdini panel, adds captured-network inspection
and focused action drafts, and introduces optional JEV action ranking alongside
the selected generation model. Solaris assembly and material reports verify
the connections they claim to have authored.

**Source release.** No new Windows installer is attached. The existing
`SYNAPSE-5.75.2-Setup.exe` does not contain these changes. Use the
[source installation instructions](../getting-started/installation.md#source-installation)
with Houdini 22.0.400 and Python 3.13.

## Panel and model choice

- One searchable picker groups **Anthropic, Google, NVIDIA, Ollama and Custom**.
  Roomier rows show readable names and exact IDs; the saved next-task model
  remains visible while filtering. Click or Enter selects; Escape dismisses.
- Search matches provider names, families, names and IDs. Exact Ollama namespaces
  and tags survive selection. Opening and searching use the cached catalog;
  **Refresh Ollama** explicitly requests model metadata.
- Cancelling Custom setup preserves the current choice. Accepting another
  provider cannot overwrite its model with an obsolete Custom ID.
- Footer text aligns with both prompt edges and wraps without overlap. Compact
  **Stop** sits below **Send**, shares its styling and stays 20 px high at normal
  scale. Cancellation remains cooperative until the worker ends.
- The standalone **TOKEN** tab is removed. Provider-reported usage still feeds
  task accounting; missing usage is not replaced with an estimate.

## Selected network

**Tools → Selected network…** captures bounded node identities, ports, internal
wires and boundary connections. The default scan reads no parameters, geometry
or USD stage. Pin the inspection to retain the captured nodes; changes to scene
identity, node identity or observed topology invalidate stale captures. The pin
scopes this inspection, not every scene-editing operation.

**Explain**, **Check wiring**, **Fix**, **Optimize** and **Inspect materials**
prepare editable drafts in the composer. Preparing a draft neither sends it nor
edits the scene. Wire insertion preview preserves endpoint ports and shows two
proposed connections through an existing selected node. Unknown ports, occupied
inputs, incomplete captures and observed cycles refuse a proposal. The preview
has no apply operation and does not establish data-type compatibility or topology
outside the observed network.

[Selected-network guide](../selection-inspector-jev.md)

**API compatibility:** `synapse_inspect_selection` now defaults to `depth: 0`,
`include_parameters: false` and `include_geometry: false`. Callers that need
upstream traversal or detailed values must opt in explicitly. Geometry reads
may cook nodes. The registered tool inventory remains 137.

## JEV assistance

In **Connect models → JEV assistance**, **Rank selected-network actions** enables
on-demand ordering of the five actions. **Measure routing** separately records
shadow judgments. Both default off, need `TYPESAFE_API_KEY`, and require the
separate TypeSafe project permission. The chosen model continues generating.

Ranking sends eligible latest intent text and public action descriptions, not
selected nodes, wiring, parameters, history or attachments. Captured context is
added locally when preparing a draft for the generator. Background requests fail
back to default actions on missing credentials, denial, contention, malformed
answers, timeouts or stale results. Ranking does not run while typing or wait on
the Send path. Routing measurement does not change prompts or narrow tools.

This release adds measurement and extension points; it does not establish
real-world ranking accuracy or latency improvement. A synthetic authenticated
JEV request succeeded, which verifies connectivity only.

## Solaris wiring

Assembly reads back each new connection's source, destination input and source
output, then verifies again after wiring and layout. Dry-run entries remain
plans. Existing nonzero output links are preserved.

Material reports list only verified authored values and shader connections as
connected maps. Unsupported or incomplete work appears as unapplied with a
partial status. Texture loading and rendered appearance are not inferred from
graph authoring; displacement remains unapplied by this tool.

## Validation and limits

- The final local product run before the version-only package stamp recorded
  **9,912 passed, 490 skipped, 11 deselected, 5 xfailed and 21 failed**. Failure IDs
  match the existing Windows harness baseline: 18 close-gate cases, two liveness
  cases and one ACL case. This is not an all-green local-suite claim.
- **205 native panel checks passed**. The independent picker replay passed
  24 cases; actual-panel review passed 25 checks. Nine screen-fit and nine
  empty-state scenarios passed at normal and enlarged scales. These suites
  overlap and are not added together.
- Selected-network backends were exercised in owned headless Houdini 22.0.400
  fixtures, including nonzero ports, dots, indirect inputs, stale captures and
  bounded scans. Offscreen Qt checks cover placement and lifecycle; the running
  Houdini GUI was not reloaded or qualified.
- One unchanged native sweep harness cannot import `pytest.mark` in its isolated
  subprocess; its source checks remain covered by stock Python. A native Qt
  entry-point diagnostic also reproduces in a standalone clear-button probe
  whose process completes successfully; its underlying cause remains unknown.
- Real artist-scene performance, live ranking quality and end-to-end speedup
  remain unmeasured. No live panel deployment is part of this release operation.

Publication requires successful GitHub CI on the exact release commit.
