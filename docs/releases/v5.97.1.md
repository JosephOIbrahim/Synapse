## The typing indicator is checked on stock Python

`9eaa6867`, merge `0305e413`.

**The template moves out of `ChatDisplay`** into `message_formatter.format_typing_indicator` (`message_formatter.py:556`). `ChatDisplay._insert_typing_html` calls it (`chat_display.py:1034`). Same template, same tokens, same escape of the sans font stack (`message_formatter.py:585`).

**The new check** in `tests/test_code_font_attr_escape.py` parses the indicator with CPython's `html.parser` for phases 0 to 2. It asserts one font-family style that carries the whole sans stack.

This closes the v5.97.0 DES-D01 follow-up (line 189).

**Where it was checked**

- **No commit records a check in an interactive Houdini session.**

**Docs**

- **The setup page says the Doctor "answers when Houdini is not ready".** True for undo off, a scene load and a missed hop. A fully stalled main thread can still refuse it: the stall gates run before the readiness check and exempt only farm controls and render polls (`v5971_cto.json`, DOCS).
- **Two other rows in that table drift from `outcomes.py`.** `houdini.busy` says "Wait 5 s"; `outcomes.py:58-59` says to wait for the cook or render to finish. `houdini.not_answering` lacks "then send it again" (`outcomes.py:60-61`).
- **No test reads the setup page's readiness table,** so a revert of this correction would pass.

**Tests**

- **On stock Python, nothing checks that `ChatDisplay` uses the escaped output.** Only the hython Qt test would catch a change that undoes the escape after the call.
- **The letter-spacing check names DATA directly and compares floats exactly.** Moving the status role off DATA would stay green, and a DATA value Qt cannot store exactly would give a false red. Qt stores letter spacing in 1/64 steps. 103 is exact, so the check is right today.

**Harness**

- **The repair covers ignored paths only.** A declared untracked path that is not ignored (`??`) and already exists in the main checkout can still be overwritten, also by a card that edits `.gitignore`. The review found the same on `38c13ea4`.
- **The `ignored` check is a directory precedent, not a file precedent.** Once a directory holds one force-tracked file, any new name in it is admitted (`harness/rope/GRAPH.md`, known limitations).
- **The new `ls-files` call takes the path as a glob.** A literal `[` in a file name would be misread. No contract name uses one.

**Still open, and not in this release.** Both are Joe's calls.

- **The demo contract has no line from Joe ratifying Jev's 2026-10-07 rulings or requiring a fresh project store per take, and no test pins one.** In `demo-round-trip.yaml`, lines 9-14 are Jev's amendments. Lines 2 and 15 are Joe's earlier ratification of the branch predicate and his stop-window ruling.
