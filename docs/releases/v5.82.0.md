# v5.82.0 — Soft Editorial panel

The native SYNAPSE panel has a more open reading column, softer cells and clearer
visual identities. Dark-grey surfaces carry coral SYNAPSE accents, sea-green YOU
labels and a separate blue-green model selector.

**Source release.** No new Windows installer is attached. The existing
`SYNAPSE-5.75.2-Setup.exe` does not contain these changes. Use the
[source installation instructions](../getting-started/installation.md#source-installation)
with Houdini 22.0.400 and Python 3.13. An already-open Houdini panel keeps its
loaded modules until it is reopened or Houdini is restarted after installation.

## What changed

- A hollow coral circle identifies SYNAPSE in the header and assistant turns.
  Message bodies remain neutral for reading; YOU has a sea-green label and rule.
- Genuine numbered assistant responses render inside a softly rounded raised
  cell with coral markers and separators. Text selection and node links remain
  native. Ordinary prose and bullets keep the open reading column.
- The inset composer and primary actions use asymmetric rounded corners. A new
  panel starts with more space for conversation; a saved composer height wins.
  Send and Stop share the coral treatment and retain their existing handlers.
- Model choice uses a stable blue-green accent, separate from connection state.
  Readable model names appear in the header; exact provider/model identity stays
  in accessible text and tooltips. Connection and task state remain available.
- The searchable model chooser uses softer selected rows, monospace exact IDs
  and row heights measured from both fonts. Search, saved choice, keyboard
  selection, Escape and asynchronous discovery keep their existing behavior.
- The assistant ring remains available after clearing the document and starting
  the next conversation. Selected model-ID ink adapts to its landing surface.

This changes panel presentation. It adds no new model requests, scene-editing
operations or JEV runtime calls.

## Validation and limits

- **141 focused panel checks passed** together using real PySide6 / Qt 6.8.3 from
  Houdini 22.0.400. They cover the composer, model picker, transcript, asynchronous
  formatting, repeated task controls, links and second conversations.
- **79 source and constructor contract checks passed**. These overlap other
  suites and are not added into a total. Superseded visual assertions were
  amended for the approved design; behavioral assertions were retained.
- Independent review compared decorated and native Qt painting across **48
  cases** with wrapped plans, selected text, narrow/wide panels, scrolling and
  second conversations. No text or selection ink was overwritten. Deliberate
  overpainting was detected in every case.
- Native previews were inspected at text scales 1.0, 1.25 and 2.25. Computer Use
  exercised the isolated preview's model search and dismissal; earlier preview
  checks exercised Send and Stop without issuing model or scene requests.
- The broad Windows run was not all green: **9,676 passed, 87 failed, 454 skipped,
  114 live-Houdini tests deselected, five expected failures and one collection
  error** from missing PyYAML. Rechecking failures with the installed async
  plugin enabled and the updated visual contracts produced **84 passed, 23
  failed and three skipped**. Remaining failures concern orchestration, package
  bootstrap, a Solaris acceptance-runner fixture and an ACL probe; not all were
  independently baseline-certified in this run. These local limits are not a
  claim that the whole repository suite passed.
- Existing native test-harness failures are documented separately from the
  focused passing checks. Qt 5 / PySide2, light or unusual host themes, live
  artist scenes and actual provider generation were not qualified here.
- The requested standard dark palette is verified. On some intermediate host
  greys, the inherited surface spread cannot support distinct identity hues at
  the target contrast; the fallback may approach white or black.
- The build-time JEV design review was not run. No live Houdini deployment is
  included in this release operation.

Publication requires successful GitHub CI on the exact release commit.
