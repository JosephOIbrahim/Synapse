capabilities easier to judge. It carries forward the v5.67.3 runtime repairs.

- Records GitHub description/topic metadata focused on Houdini, artists, local/cloud models, Solaris and MaterialX.

until a matching rehearsal/import is available. Existing records are retained.

diagrams** rendered in both light and dark themes, narrow-screen README layout,
and **54 version, tool-count and public-metadata contract tests**. Independent
source review checks the documentation against the implementation. The release is published
only after CI passes on its exact commit. Native and live qualification limits
remain those documented in [current status](../status.md); no new live demo,
model traffic, real-store end-to-end run or render is claimed here.
