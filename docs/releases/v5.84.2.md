# v5.84.2 — JEV / TypeSafe key setup

**Connect models → JEV / TypeSafe key setup** now leads directly to a labeled,
masked API-key field. Save or clear a session key without changing your chosen
generation model, enabling JEV, or granting request permission.

Saved keys stay in process memory until Houdini closes and survive panel refreshes.
Unsaved input is discarded when the dialog closes. Clearing a session key restores
the existing environment-key fallback, if configured, and the status explains it.
Keys are not written into panel settings. Saving reports **Validity has not been
checked**; it does not claim that TypeSafe accepted the key.

See the [JEV setup guide](../getting-started/jev-setup.md) for key entry,
preferences and permissions. This release includes the previous panel, welcome,
World Labs and SideFX library work through [v5.84.1](v5.84.1.md).

**Source release for Houdini 22.0.400 / Python 3.13.** No new Windows installer is
included. The older v5.75.2 Setup does not contain these changes. Follow
[source installation](../getting-started/installation.md#source-installation),
then restart Houdini and separate MCP processes to load the updated source.

## Validation and limits

The release candidate passed 132 checks using Houdini 22.0.400's Python and native
Qt, covering credential lifetime and precedence, keyboard entry, dialog
interactions, JEV transport and permissions, existing submenu behavior, and
version/public-surface conformance. Four deliberately broken implementation
variants were caught by their regression tests. Independent review checked
the implementation and the bounded live refresh. Computer verification observed
the setup shortcut in the running Houdini panel.

Actual TypeSafe authentication was not attempted with a real user key. The key
status describes availability, not service validation. Existing permission and
opt-in requirements remain in force. Publication requires successful CI on the
exact tagged commit, linked in the GitHub release.

The inherited [v5.84.1 limits](v5.84.1.md#validation-and-limits) remain, including
incomplete SideFX fetch coverage, short-dock overflow, and unqualified remote
World Labs export and alternate themes. Local documentation caches and library
databases are not bundled.
