# v5.76.1 — the harness learns to judge before it spends

**No product change.** The installer is the 5.75.2 build; nothing under `panel/` or `synapse/` changed. This release lands in the build harness only.

## What changed

**Jev joins the BATTLEPLAN harness as typed guard nodes.** [TypeSafe's System One model](https://docs.typesafe.ai) returns calibrated judgments, not text. It now sits on two edges of the wave graph:

- **JEV-ROUTE** — a mission authored with `"tier": "auto"` is routed to a tier name from `harness/rails_exec.json` at compile time. Three judgments feed one plain-code policy (tier choice, novelty score, blast-radius score); doubt rounds up to `reasoning`. Shadow run on wave BP4: 8/8 agreement with the hand-authored tiers.
- **JEV-SCREEN** — each builder receipt is judged per acceptance row: does the evidence text support the predicate? The result is one line per builder in the CRUX referee's brief, setting where the referee starts reading. It never removes the referee. Prompts compiled without a screen ledger are byte-identical to before.

**Fail closed, every call ledgered.** No API key, SDK error, or network fault produces a `fallback` row under `harness/jev/ledger/` and the pre-Jev behaviour (`reasoning` tier; full referee read). `SYNAPSE_JEV=off` is the kill switch.

**Fourteen biting tests** under `harness/jev/tests/`, each with a named mutation that reddens it (see `harness/notes/receipts/BP6-JEV.json`).

**First mission routed by Jev shipped on the tier Jev chose.** BP6-JEV, the leg that hardened this seam, was itself routed `reasoning @ 1.00` (`harness/jev/ledger/bp6.route.jsonl`).

## Why 5.76.1 and not 5.76.0

`v5.76.0` was tagged on a commit whose CI was red: the README release-tag line still read 5.75.2 (the version sync does not touch it), and one doc-conformance test pinned a sentence that a 2026-09-18 CLAUDE.md rewrite had restated in prose. The release gate refused, as designed. Both are fixed here; the test now pins the facts, not the phrasing. `v5.76.0` stays in history as a tag that never became a release.
