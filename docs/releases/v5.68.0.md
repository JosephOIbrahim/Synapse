# v5.68.0 — Graph review controls and Windows Setup

SYNAPSE now separates worker proposals from reviewed host graph application.
This release also brings the existing Windows installer implementation into the
main source tree and packages it with the current runtime.

## Changes

- Add the opt-in `proposal` worker policy: registered reads, actual knowledge
  tools and declared proposals remain available; direct mutations and graph
  instantiation are denied to the worker. The default stays `standard`.
- Classify `synapse_instantiate_graph` as `build_from_manifest`, which requires
  review on the bridge path. The separate live WebSocket path is unchanged.
- Record graph qualification on Houdini 22.0.400 and 22.0.417, with matching
  implementation hashes and a verifier that rejects missing or mismatched evidence.
  Builder/oracle runtime algorithms are unchanged.
- Keep graph evidence fingerprints consistent across Python 3.11–3.14 without changing the recorded Houdini receipts.
- Include the previously published Windows Setup implementation and shared
  package/UI registration helpers, now built for 5.68.0.
- Put download, four setup steps, a first task and troubleshooting at the top
  of the README. Keep memory and developer details expandable.

## Verification scope

The G1/G2 source deployment passed **433 tests**. The running Houdini 22.0.400
session was read back: five modules and 32 loaded functions matched the deployed
source, and the worker used the updated policy. Its unsaved scene stayed open.
The graph fixture passed separately on both .400 and .417.

Release assets contain the installer checksums and a public build report.
The GitHub release records the additional installer qualification and the CI
result for the exact release commit. Earlier reports are historical evidence;
they are not substituted for checks of the new installer.

## Update

Save your scene and close Houdini before using the unsigned Windows Setup.
Download `SYNAPSE-5.68.0-Setup.exe` from the release assets. Existing source
installations can instead follow the [source setup guide](../getting-started/installation.md#source-installation).

## Still unfinished

- Full product-level Computer Use controls, predictive creation and later
  SYNAPSE v2 blueprint waves remain development work.
- Proposal mode is opt-in. This release does not enable it on existing seats.
- The installer/full panel target is .400; .417 evidence covers the graph fixture.
- Code signing, a clean Windows machine, native wizard visual inspection,
  historical installer upgrades and live model/render qualification remain
  separate checks unless the release report explicitly supplies new evidence.
- Optional Moneta/Octavius/Hanish integrations require their own configured
  services; an import/schema check is not an active memory persistence test.
- Existing Python 3.14 vendored-SDK ABI warnings remain. Houdini uses its bundled
  Python 3.13.
- Older Stage 0 experiences need a matching rehearsal/import for version 5.68.0.
