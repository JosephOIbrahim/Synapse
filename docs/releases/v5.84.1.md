# v5.84.1 — Shorter Resize label

The prompt resize handle now reads **Resize**. This is the only runtime change
since v5.84.0; dragging, keyboard adjustment, saved sizing and styling are
unchanged.

This patch includes the completed panel, submenu, welcome, World Labs and
SideFX library work from [v5.83.0](v5.83.0.md) and [v5.84.0](v5.84.0.md).
It brings the release up to date with the final label revision made on
24 September 2026.

**Source release for Houdini 22.0.400 / Python 3.13.** No new Windows installer
is included. The older v5.75.2 Setup does not contain these changes. Follow
[source installation](../getting-started/installation.md#source-installation),
then restart Houdini and separate MCP processes to load the updated source.

## Validation and limits

The release candidate passed 49 existing checks using Houdini 22.0.400's
Python 3.13 and native Qt: four grip behavior checks, 11 version checks,
28 tool-count/public README checks and six product-surface checks.
Computer verification observed the new label in the open Houdini 22.0.400
panel; the live update preserved focus and widget geometry. Publication
requires successful CI on the exact tagged commit, linked in the GitHub release.

The validation boundaries from v5.84.0 remain: the local SideFX snapshot has
439 upstream HTTP 404s and incomplete fetch coverage; at a 341 × 760 dock
with 2.25 scale, the resize rail adds 29px to pre-existing footer overflow.
The label-only patch does not resolve those limits or add installer, remote
World Labs export, end-to-end model-response or alternate-theme qualification.
Downloaded documentation and local library databases are not bundled.
