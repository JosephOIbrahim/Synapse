# v5.77.1 -- Jev may cross into the product, through one fenced door

**No product change.** This release amends one governing rule, adds one test that pins it, and publishes the report that argued for it. The product-surface diff against v5.77.0 is the version string in `python/synapse/__init__.py` and nothing else (`python scripts/product_surface.py --diff v5.77.0 HEAD`, 1 file, 2 lines).

**No new installer in this release.** The `SYNAPSE-5.75.2-Setup.exe` the README links is the last built installer. Nothing in this tag changes what an installer would carry.

## What changed

**Invariant 5 of the Jev harness is amended and ratified.** Until now `harness/jev/README.md` said, verbatim, "Jev is never on the product path." That sentence blocked every artist-facing use of a typed judgment: stopping a runaway tool loop, asking the artist before a denied tool instead of quietly doing less, hinting the model toward one build call. Joe ratified the amendment on 2026-09-21. The rule now reads: Jev is off the product path by default, and on it only through a package-side adapter under `python/synapse/` that meets all six conditions.

- (a) A hard timeout of at most 800 ms. Never raises. Returns None on any failure, so the offline behaviour is byte-identical to today's.
- (b) `SYNAPSE_JEV=off` is honoured in-product.
- (c) `TYPESAFE_API_KEY` is resolved once through the providers' `resolve_key` pattern and never logged.
- (d) Its ledger lives under `~/.synapse/`, never in `synapse.log` and never in `harness/jev/ledger`.
- (e) It is never called inside a `run_on_main` / `main_thread_exec` closure. It runs on the worker or daemon thread after the marshal returns.
- (f) It ships shadow-first: the judgment is ledgered beside today's decision and graded against a named answer key before any threshold is allowed to change behaviour.

A Jev answer never grants consent, never names a model, never writes a scene. The same text is in `harness/battleplan/notes/JEV_BLUEPRINT.md` sec. 4, now v0.2.

**The boundary is pinned by a test.** `tests/test_jev_product_boundary.py` fails if anything under `python/synapse/` or `shared/` imports the build-time harness (`harness/jev`, `jev_client`, `jev_route`, `jev_screen`), and fails if the README ever drops one of the six conditions. Two tests, both green.

**The report.** `docs/reviews/jev-opportunities-2026-09-20.md` answers "where does a typed judgment earn its call in this repo". Live TypeSafe docs were read first (primitives, confidence, the jev-1.13 jaggedness page, seven cookbooks). One dynamic workflow then ran 30 agents: 8 read-only cartographers over 8 seams, one triage, one crucible attack per finalist, one docs-fit reshape per survivor, one completeness critic. 38 candidate judgment points were found and 94 were rejected as not Jev-shaped. 12 finalists, 8 survived attack, 4 were broken and kept as pure-code work.

Shippable now, invariant intact, in order: a gate-table drift lint (six hand-maintained risk tables disagree today; the deterministic half needs no key), a recall-quality oracle over a copied memory store, a CTO SYNTH triage guard, a stale-leg transcript classifier in shadow, and a scout shadow reranker. Unblocked by this amendment: a tool-loop drift nudge, a build-shape hint before the first LLM turn, and the worker denial turned into a consent card. Each of those three has a zero-Jev phase that ships regardless.

**The shipped guards, graded.** `python harness/jev/jev_grade.py` replays every ledgered answer with zero new calls. On n=8, SCREEN's current policy has never said CLEAR and said REFEREE on the one BROKEN leg; the `flag-on-contradiction` candidate policy is the only one that catches it. ROUTE on the one live `tier: auto` wave rounded every mission up to `reasoning` at confidence 0.16 to 0.57. Mission notes open with a literal "Tier: mechanical (Haiku 4.5)" sentence, which could have made the shadow agreement a leak; a re-run with every tier and model word scrubbed still agreed 12 of 12 (`harness/jev/ledger/leakprobe-bp4.shadow.route.jsonl`, `leakprobe-bp8.shadow.route.jsonl`). The judgment is real.

## Not in this release

- No adapter is built. The amendment licenses one; it does not ship one.
- The SCREEN policy change (`flag-on-contradiction`) is a one-line edit to `harness/jev/questions.json` and is not made here. The grade is evidence for a ruling, not a ruling.
- `harness/jev/tests/` is still outside `pyproject` testpaths and `ci.yml`. The new boundary test lives under `tests/` so it does run in CI.
- Eight plain code bugs surfaced by the scouts (section 7 of the report) are recorded, not fixed.
