# v5.85.1 — Claude Code connects to SYNAPSE

**Claude Code can now use SYNAPSE's tools.** SYNAPSE's `/mcp` endpoint read request
headers with a case-sensitive lookup. HTTP header names are case-insensitive, and
Claude Code sends them in lowercase. So Claude Code connected but loaded no tools,
with the error "Missing Mcp-Session-Id header". SYNAPSE now reads headers
regardless of case. The [MCP setup guide](../mcp/SETUP.md#claude-code) shows the
Claude Code steps that were verified live.

The same fix closes a gap in the check that refuses requests from web pages. A
request that spelled its `origin` header in lowercase was treated as having no
origin, which that check allows. The WebSocket bridge used the same lookup and is
fixed too.

**Newer Claude models in the model menu.** Claude Fable 5.1, Opus 5.5 and Sonnet 5.5
now sit at the top of the Anthropic list, with their context sizes and list prices.
Every older model stays, so a saved pick keeps working. The default stays Sonnet 4.6
until Sonnet 5.5 passes a live test in the panel.

**Source release for Houdini 22.0.400 / Python 3.13.** No new Windows installer is
included. The older v5.75.2 Setup does not contain these changes. Follow
[source installation](../getting-started/installation.md#source-installation),
then restart Houdini and separate MCP processes to load the updated source.

## Validation and limits

The header fix was checked against the running server in Houdini 22.0.400. Before
the fix, a lowercase `mcp-session-id` header got "Missing Mcp-Session-Id header",
while the exact capitalization listed the tools. After a restart, both listed the
tools. Claude Code 2.1.284 then reported the server as connected, loaded all 137
tools, and answered a read-only question from the open scene. Its answers for the
Houdini version, the scene file and the selection count matched the screen.

A new test drives the `/mcp` handler with lowercase headers. The session is found,
a foreign origin is refused, and a missing token is refused. With the old handler,
that test fails. The full `tests/` suite and the JEV harness tests passed locally on
Windows. Publication requires all six GitHub CI jobs to pass on the exact tagged
commit, linked in the GitHub release.

Anthropic's live model list for this account includes all three new models, and
their context sizes and prices match Anthropic's pages on 2026-09-28. No completion
was run on them through SYNAPSE's panel, because the only API key available had no
credit. That is why the default model did not change.

External MCP clients do not inherit the panel's restricted tool policy. Claude Code
asks before each tool call unless a permission rule allows it, and SYNAPSE assumes a
single-user, localhost setup. See [authentication](../mcp/SETUP.md#authentication).

The inherited [v5.85.0 limits](v5.85.0.md#validation-and-limits) remain, including
the long first save of an untitled scene and the Identify limits.
