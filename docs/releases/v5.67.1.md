# v5.67.1 — Lookdev verification and task recovery

This patch strengthens verification of the fixed Solaris/Copernicus lookdev fixture and preserves useful conversation history when a panel task stops or fails.

- **Recover with the actual tool results.** After Stop or a later provider/permission error, the next request retains completed tool results and an explicit task-status note. Results that were never received remain unknown; calls that were never dispatched are identified separately. The panel does not automatically replay the unfinished plan, and late signals from an older worker cannot finish a newer task.
- **Check the plane and its UVs more precisely.** The fixture verifier now rejects collapsed, nonfinite, displaced or incorrectly sized geometry, crossing face order, surface-direction changes, subdivision changes and incorrect UV-to-corner associations. Equivalent point numbering, indexed UV storage and equivalent orientation remain accepted.
- **Verified save/reopen preservation.** In the disposable Houdini 22.0.400 qualification, nondefault color, roughness and node-position edits survived saving and reopening the same HIP. The authored snapshots matched, and the reopened fixture passed the full USD verifier. The already-saved artist example also passed the stricter verifier in a disposable Houdini process, with its original file bytes unchanged.

The supported lookdev workflow remains the fixed Houdini 22.0.400 fixture: modern Copernicus RGB color and procedural roughness inside Texture Material Library, connected to a USD material. The existing **v5.67.0 rendering qualification remains unchanged**; this patch adds no new rendering or pixel qualification.

Feature checks passed independently: **354 task-history and related checks, with 19 unavailable Qt-widget skips**, plus **117 assertions using real Qt thread/signal delivery**; **107 fixture-verification checks** plus **17 native Houdini checks on the combined version**. Five transcript mutations and six geometry-verifier mutations were rejected by the regression tests.

These changes do not guarantee that a model follows a read-only instruction, and they do not establish the cause of the recorded DeepSeek instruction-following failure. Arbitrary assets, automatic copied-fixture or saved-recipe rebinding, export packaging and render-farm workflows remain outside this qualification. Save/reopen evidence concerns the same fixed fixture and its authored state.

**Restart Houdini after updating the local Python files.** An already-running session continues using its loaded code; these notes do not attest to installation in a live session.

The [v5.67.0 qualification limits](https://github.com/JosephOIbrahim/Synapse/blob/v5.67.0/docs/releases/v5.67.0.md) still apply, including the fixed 256-pixel preview, in-session `op:` texture references, permission boundaries and recorded wider-suite baseline failures. The standing requirements `mutation_fail_closed`, `hot_reload_gated`, `installer_host_targeted` and `ci_covers_shipping_surface` remain open. The Latest designation does not close them.
