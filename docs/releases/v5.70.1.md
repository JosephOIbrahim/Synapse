# v5.70.1 — The front door, made readable

Nothing that runs changed. What you read did.

If 5.70.0 works for you, 5.70.1 is optional: the panel, the tools and the
installer payload's code are identical apart from the version string. This release exists so the first
things an artist reads — the README and the setup guide — say the right
thing in a form that can be scanned, and so the repository carries its own
working state instead of leaving it on one machine.

## Changes

- **README rewritten for scanning.** Same facts, one idea per block. The
  three stop controls, the first-build steps and the "when you get stuck"
  table are unchanged in substance; the walls of text around them are gone.
  The one number the README carries — 128 tools — now names its producer:
  `len(TOOL_DEFS)` in `python/synapse/mcp/_tool_registry.py`, pinned by
  `tests/test_phase0c_doc1_toolcount.py`.
- **Setup guide links corrected.** `docs/getting-started/installation.md`
  still sent artists to the 5.68.0 download and checksums — three releases
  behind. Found by a first-principles audit of the release surfaces; fixed.
- **Harness state is in the tree.** Seven of the twelve harness boards, the
  reach and flow agent definitions, the 2026-09-06 UX harness handoffs and the
  2026-09-15 closeout, harness-review and first-principles audit notes were
  untracked. They are committed now; run artifacts (XML dumps, `.hiplc`
  scenes) are ignored by `harness/*/artifacts/` and stay out of history.

## Verification scope

Measured on this build, alone, in this order. Nothing here was retyped from a
previous release.

- Stock suite: **8920 passed, 430 skipped, 625 warnings in 346.60s (0:05:46)**
- Panel seat suite under hython 22.0.400 offscreen: **5 failed, 201 passed, 38 warnings in 75.63s (0:01:15)** — the
  known five reds from 5.69.0 / 5.70.0; none new.
- Installer unit checks: **37 passed, 1 warning in 7.92s**
- Installer qualification: **19 of 19 PASS, exit 0** against the isolated TestSetup,
  which carries the same payload sha256 as the published Setup
  (`e603cfb3386579710fa5735c26ba69ca220fbbcc10de15929b5b4ebf2d186406`).
- `python/` and `installer/` differ from v5.70.0 only by the version string in
  `python/synapse/__init__.py`: `git diff --stat v5.70.0 v5.70.1 -- python installer`
  shows that one file, two lines. The payload was built from the bumped tree,
  so payload and tag agree. The release notes and changelog were written after
  the build from the measured numbers, so the payload's copy of `docs/` is one
  edit behind the tag; the product is not.

## Update

`SYNAPSE-5.70.1-Setup.exe` upgrades in place and preserves projects, memory,
credentials and custom files — that path is one of the qualification checks.

- Running from source? Pull `v5.70.1`. A live Houdini session keeps whatever
  modules it already loaded; there is nothing new to load in this release.
- The installer is **unsigned**; verify against `SHA256SUMS.txt`.
- `installer-verification.json` on the release carries the full evidence,
  including anything that was not run.

## Still unfinished

Unchanged from 5.70.0, and still true:

- Five panel seat tests remain red. Two are design conflicts awaiting a ruling
  (the Doctor button's approved accent against the monochrome ceiling; J5's edge
  air against BC-5's transcript share at airy); three are named and undiagnosed.
- **The suite's skip population is not stable.** 21 tests are disabled by a
  symbol missing from an out-of-tree dependency, and no gate in this repository
  can see it. See `harness/notes/SUITE_FLOOR_IS_NOT_STABLE.md`.
- `QMenu` modals can still hang a seat test; the guard covers dialogs and the
  C++ static helpers, and documents the hole rather than implying it is closed.
- The panel's emergency halt **fires** but does not survive a frozen main thread.
- Code signing, a clean Windows machine and native wizard visual qualification
  remain separate checks.
- A message typed while the bridge is down is accepted and queued without a
  visible signal, then replayed when the bridge returns. Found by code reading
  in the 2026-09-15 artist-surface review (`harness/notes/closeout-2026-09-15/`);
  not yet reproduced in a live session, not yet fixed. Until it is: if **Connect**
  shows the bridge down, wait for it before sending.
