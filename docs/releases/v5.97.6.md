# SYNAPSE v5.97.6

This patch corrects Windows Setup configuration preservation and provides an
execution-gated native artifact for Windows x64, Houdini 22.0.400 and Python
3.13.10. It carries forward the 5.97.5 runtime scope. The original 5.97.5 tag and
assets are preserved.

## What changes

- Explicit OFF and existing default-OFF registrations remain OFF. Supported
  custom environment entries and extra import paths survive manual migration.
- Fresh supported installations and existing ON setups require a compatible
  hash-pinned artifact and actual primary Moneta storage, Rust scan/decay,
  encrypted mirror and fresh-process reopen checks before ON activation.
- Without an explicit ON choice, missing native artifacts or unsupported fresh hosts report native UNAVAILABLE
  and remain OFF. Explicit ON (including inherited environment choices) with unavailable qualification or failed checks refuses activation.
- Edited managed packages, ambiguous registrations within one preference folder, conditional settings and
  custom Houdini paths refuse automatic migration. Configuration and package
  namespace edits during qualification are preserved and refuse activation.
- The rebuilt native artifact removes known personal build paths and includes
  exact source files, owner grant, portable SBOM and third-party notices. Its
  four source hashes are recorded; native source Git HEAD remains **UNKNOWN**.

## Tests

The [final installer verification](https://github.com/JosephOIbrahim/Synapse/releases/download/v5.97.6/installer-verification.json)
and [public build record](https://github.com/JosephOIbrahim/Synapse/releases/download/v5.97.6/SYNAPSE-5.97.6-Setup.public-build.json)
bind qualification to the exact final Setup, payload and source revision.
The release page links the CI run for that exact commit.

- 84 installer tests and 34 source-package regression tests pass. New controls
  were observed failing before their fixes or under deliberate isolated mutations.
- All 14 independent adversarial preservation/namespace controls pass; their
  earlier failures were retained and corrected before release.
- The rebuilt binary passes Moneta’s full 907-test H22 suite: all 71 required
  native cases, both qualification lifecycles, 594 real scan and 795 real decay
  calls. Intentional fallback controls are recorded separately; no unexpected
  fallbacks occurred.
- Disposable composed migration, repeat and uninstall retain mixed ON/OFF
  choices and restore original registration bytes. Existing default-OFF stays OFF.
  Actual SYNAPSE primary-Moneta scan/decay and encrypted-mirror save/reopen ran
  in fresh headless processes with disposable data and keys.

## Signing

Setup is **unsigned**. The inspected workstation has SignTool but no configured
authorized publisher signing identity. No signing credentials were created and
no security settings were changed. Check the download checksum; do not bypass
a security warning.

## Limits

Extraction and embedded-engine checks do not establish an interactive wizard,
clean-machine install or arbitrary artist GUI behavior. Local installation and
normal-startup evidence are separate from public artifact qualification. No
production stores, original artist scenes or credentials are release fixtures.
Native activation proves the measured host/configuration and disposable data,
not every future store, plugin, scene or failure. Native source Git provenance
and complete reproducible-build provenance remain limited.

The [5.97.5 tests and limits](v5.97.5.md) remain applicable: eight panel failures
match baseline, full RC+ξ is not activated, and the existing bounded LIGHT
operation remains experimental. Panic containment is preserved; synthetic panic
controls do not prove every native failure mode. No Houdini upgrade is included.
