# v5.85.5 — The older panel is retired

**The older `synapse.ui` panel is gone.** SYNAPSE shipped two panels. The one
Houdini loads, `synapse.panel.synapse_panel`, is unchanged. The other, in
`python/synapse/ui`, was built by nothing in the product and shared its class
name with the live one. It is removed, along with its five tabs.

**Four names left the public surface.** `synapse.SynapsePanel`,
`synapse.NexusPanel`, `synapse.create_panel` and `synapse.UI_AVAILABLE` used to
import that older panel on first access. They now raise an `AttributeError`
that names `synapse.panel.synapse_panel.SynapsePanel`. Nothing in SYNAPSE used
them. Code outside this repository that did will need to switch to the live
panel module.

**A correction to v5.85.4.** Its notes said the Clear All Memories button could
hang Houdini. That button was on the older panel, which the registered Houdini
panel never loaded, so a normal session could not reach it. The v5.85.4 notes
here and on GitHub now say so. The lock fix itself stands.

**Source release for Houdini 22.0.400 / Python 3.13.** No new Windows installer
is included. The older v5.75.2 Setup does not contain these changes. Follow
[source installation](../getting-started/installation.md#source-installation),
then restart Houdini and separate MCP processes to load the updated source.

## Validation and limits

The registered panel was checked in `hython` on Houdini 22.0.400 after the
change. Its module imports, `onCreateInterface` is present, `synapse.ui` is not
loaded, and `create_panel` raises the pointer. Six new tests keep the older
tree from coming back and keep the four names raising. They also pin that the
registered pane loads the live panel and never the older one. Against the
previous tree, five of them fail.

The full `tests/` suite passed locally on Windows with Python 3.14, with the
tests that need a Houdini runtime deselected: 10,177 passed, 457 skipped, 0
failed. A comment-only commit followed it, and the retirement, version and
feature tests ran again after it. The except ratchet went down, from 1,379 to
1,366 broad handlers and from 995 to 987 silent ones, because the removed files
held them. Publication requires all six GitHub CI jobs to pass on the exact
tagged commit, linked in the GitHub release.

Some limits remain. The live pane was not opened in the Houdini GUI after the
change; the import check ran in `hython`. The Moneta store still cannot be
cleared, and nothing in SYNAPSE asks it to. Code outside this repository that
imported the retired names is not visible to these checks.

The inherited [v5.85.4 limits](v5.85.4.md#validation-and-limits) remain.
