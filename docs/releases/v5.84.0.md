# v5.84.0 — SideFX help library and clearer prompt controls

Scout can now search a local library of installed Houdini help and official
SideFX Markdown. The panel also gives prompts more initial room and makes
resizing easier to discover, with consistent dark-gray interaction outlines.

**Source release for Houdini 22.0.400 / Python 3.13.** No new Windows installer
is included. The existing v5.75.2 Setup does not contain these changes. Follow
[source installation](../getting-started/installation.md#source-installation)
and restart Houdini and separate MCP processes after updating.

## SideFX library

- A bounded, resumable downloader starts from the official `llms.txt` index,
  preserves original Markdown, follows discovered documentation links and
  records failures. Refreshes use HTTP validators and verified cached bytes.
- The builder inventories installed help, records source/build provenance and
  publishes immutable SQLite FTS5 generations through an atomic pointer.
  Unchanged inputs reuse the verified search generation.
- Scout reads a bounded shortlist without downloading or rebuilding on the query
  path. Named documentation subjects and methods receive stronger matching.
  Missing or corrupt libraries report unavailable while other Scout sources remain.
- Documentation remains document evidence. Runtime API membership still comes
  from the introspected Houdini symbol table; newer web help cannot establish
  that a symbol exists in the current runtime. APEX callbacks keep their existing
  dedicated provider.

Use the [library setup guide](../studio/SIDEFX_LIBRARY.md) to build and connect
your own cache. Documentation and generated databases are not added to Git or
release assets. Updates run on demand; no scheduled job is installed.

The validation machine indexed 21,165 pages into 110,049 chunks from installed
and online sources. Its traversal accounted for every discovered link, but
439 official links returned HTTP 404, so `fetch_complete` remained false.
These are local snapshot measurements, not a claim that every SideFX page is
available. The default updater preserves the active generation when web fetches
fail; `--allow-incomplete-web` explicitly permits available pages with visible
gap counts. Installed wiki text retains unexpanded directives.

## Panel interaction

- The prompt composer starts taller. A visible **Drag to resize** handle shows
  where to change its height; keyboard adjustment and saved user sizing remain
  available. The handle label fits fractional host scaling.
- The footer's Render shortcut is removed and its remaining controls use a
  compact layout. The render workspace remains available through Commands.
- Search, filter, tab and keyboard-focus outlines use the footer's dark gray.
  Model rows and the resize handle use the same shared outline role. Coral
  identity text, selected fills and primary actions retain their established colors.

## Validation and limits

The composed release check passed 287 tests using Houdini 22.0.400's Python 3.13
and native Qt. It covers the panel, model picker, submenus, World Labs dialog,
SideFX library/download/Markdown paths, version agreement and public surfaces.
One Windows symlink-privilege check skipped. Publication requires successful
GitHub CI on the exact release commit; the published release links that run.
An additional 115 environment and panel-guard tests passed after documenting
the SideFX override and narrowly updating the guards for the approved resize
and neutral-outline changes. Their original baselines and negative controls
remain in place.

The open Houdini 22.0.400 session was checked after the panel changes. Live
snapshots preserved conversation/draft state, model choice, focus, visible
geometry and scene metadata during the color update. Native render probes
measured matching gray outlines at 1.0 and 2.25 scale.

The SideFX live check used Scout's lexical path; it did not generate an
end-to-end model response. Coverage cannot prove that unlinked online pages are
absent. Optional dense-search substrates and Windows symlink privileges remain
environment-dependent.

**Small-dock limit:** at 341 × 760 with 2.25 scale, the labeled resize rail adds
29px to the pre-existing footer overflow. The tested 341 × 900 dock and actual
larger live dock fit. The narrower layout limits recorded in
[v5.83.0](v5.83.0.md) are not fully resolved. This release does not claim broad
Windows native-suite or alternate-theme qualification. World Labs remote export
and rendering limits from v5.83.0 are unchanged.
