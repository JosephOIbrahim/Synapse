# v5.69.0 — The stop controls actually stop

This release is about the controls an artist reaches for when something is going
wrong, and about records that stopped quietly lying. It ships with a qualified Windows Setup — see [Update](#update).

## Changes

- **The emergency halt fires when another panel tool is already running.** The
  re-entry guard in `_run_direct_tool` keyed on *any* live direct-tool call, so
  cancelling a cook and then choosing Emergency halt dropped the halt silently
  while the rail read `Still Emergency halt…` — which reads as *in progress*.
  The guard is now per verb. Measured before and after: `calls_started` delta
  `0 → 1`, `halt actually dispatched` `False → True`.
- **A refused panel request says so.** That guard used to `return` without firing
  either of `DirectToolCall`'s two terminal signals, so nothing reported at all.
- **A REVIEW consent card no longer files a rejection that never happened.**
  Choosing REVERT while the worker was streaming tore the card down, stamped
  REJECTED, wrote `GateDecision.REJECTED` against a proposal the bridge had
  already allowed, and said so in the transcript. None of that had happened. The
  card now survives the refusal and settles neutrally when a request does go out.
- **The system-prompt fallback announces itself** instead of substituting silently.
- **Session journal entries carry a date**, so a session can be bounded across days.
- **`log_decision` no longer discards out-of-schema payload keys** without saying so.
- Add a detector for a LOP catalog stamped on a build the runtime has moved past.
- Give `baseline.csv` a reconstructed, tested producer, so every number in it is
  re-derivable rather than folklore.
- README: the three stop controls, and what each one does *not* do.

## Verification scope

- Suite at tag time: **8908 passed, 430 skipped, 0 failed, 0 errors** on local
  Windows, stock Python, vendored SDK inactive.
- Panel seat suite under hython 22.0.400 offscreen: **201 passed, 5 failed, 76s**.
  It previously **hung forever** on a modal dialog — three of those tests had
  never executed on any machine. The five remaining failures are named and open;
  two are design conflicts recorded for ruling, not defects.
- The halt fix was measured with a re-runnable probe on two trees, not inferred.
- Rail width claims are in **pixels** from `fontMetrics().horizontalAdvance`
  under hython with the bundled fonts loaded — not glyph counts.

NOT RUN when this release went out. Both were run afterwards and the published
`installer-verification.json` was amended in place rather than leave a false NOT RUN
standing:

- **installed_houdini — PASS.** Separate headless Houdini 22.0.400 with offscreen Qt:
  `tests/panel/` 201 passed, 5 failed, 72s. The five are named in the report; two are
  recorded design conflicts awaiting a ruling, three are named and undiagnosed, and
  none is new in 5.69.0.
- **live_houdini — PASS**, read-only against a running Houdini. It answers the question
  that matters and that source inspection cannot: **is the fix in the process?** A
  stale module would report the new version string from `__init__` while still running
  the old guard. Measured live: the per-verb guard is present, the refusal message is
  present, the old single-slot guard is gone, and F4's `mark_revert_sent` exists.
  `scene_unchanged: true` — 55 nodes before and after, zero diffs, nothing created,
  set, cooked or rendered.

## Still unfinished

- **The suite's skip population is not stable.** 21 tests are disabled by a
  symbol missing from an out-of-tree dependency, and no gate in this repository
  can see it. See `harness/notes/SUITE_FLOOR_IS_NOT_STABLE.md`.
- **`QMenu` modals can still hang a seat test.** The new guard covers dialog
  `exec()` and the C++ static helpers; a patch on `QMenu.exec` was measured to
  install and do nothing, so it is documented as an uncovered hole with four
  live call sites rather than implied to be closed.
- The panel's halt now **fires**; it does not survive a frozen main thread. It
  marshals through `run_on_main(..., timeout=60.0)`. The freeze-proof
  `emergency_halt_live` is reached only from the freeze chain.
- Two artist-visible design conflicts are recorded and unruled: the Doctor
  button's approved accent against the monochrome ceiling, and J5's edge air
  against BC-5's transcript share at airy.
- `migrate-wiring` remains held; its ruling is re-priced, not reversed.
- Full product-level Computer Use controls, predictive creation and later v2
  blueprint waves remain development work.
- Code signing, a clean Windows machine, native wizard inspection and live
  model/render qualification remain separate checks.
- Older Stage 0 experiences need a matching rehearsal/import for version 5.69.0.
