# v5.83.0 — Panel continuity, welcome motion and World Labs

SYNAPSE's native panel now carries its dark-grey and coral design through the
footer, composer and submenus. The release also adds an animated ASCII welcome,
an explicit World Labs import flow, and a SideFX Markdown adapter for Scout.

**Source release for Houdini 22.0.400 / Python 3.13.** No new Windows installer
is attached. The existing v5.75.2 Setup does not contain these changes. Use the
[source installation instructions](../getting-started/installation.md#source-installation)
and restart Houdini after updating to load the new Python modules.

## Panel and welcome

- Footer actions have rounded inset backgrounds and equal column widths.
  Cloud relay and Connect models align with the controls above; World Labs sits
  beside Cloud relay. Narrow panels rearrange the controls without overlap.
- Attach and Send match the composer design. Header and footer padding balance,
  and the keyboard hints use the status label's letter spacing.
- Model selection and menu highlights use the SYNAPSE circle's coral accent.
  Model-picker heading and detail text have more space. Connection details,
  Doctor, commands and other native submenus share the same design system.
- The centered welcome uses uppercase WELCOME TO, dimensional ASCII SYNAPSE
  lettering and a fitted single-line helper. The wordmark is three points larger.
  Very narrow panels preserve access to the complete helper through its tooltip.
- The whole welcome drops in over 320 ms, then rises and fades over 200 ms when
  typing or an action begins. It does not move the transcript or composer.
  Resizing and reopening a dock do not replay it; reduced motion settles instantly.

## World Labs import

Open **World Labs**, beside **Cloud relay**. Paste a supported Gaussian `.ply`
path to import locally, or enter a World Labs API key in the masked field and
choose **Connect World Labs**. The key stays in session memory; `WLT_API_KEY` in
the environment is also supported. Enter a world ID/Marble URL or select from
up to 50 recent successful API worlds, choose resolution, then **Import world**.

The client exposes only reads and the documented
[free splats/PLY export](https://docs.worldlabs.ai/api/pricing). It provides no
generation or mesh-export action. Downloads run outside Qt, carry no API-key
header, and are validated before import. Closing or pressing Escape invalidates
pending results so reopening the dialog cannot import an old request.

The native route is File SOP → Bake GSplats → SOP Import LOP. It validates the
result as `ParticleField3DGaussianSplat`, groups the scene change into one undo,
records provenance on created nodes, and removes new nodes if construction fails.
It creates a separate branch and does not merge into existing stage wiring.
The supported PLY layout has either no higher-order SH data or degree-3 SH data.
Ordinary point PLY, SPZ and mesh GLB are not interchangeable inputs.

**Limits:** authenticated remote export/download and access to Marble-app worlds
were not verified in this release. A real local 500,000-splat Marble fixture was
converted in a separate Houdini 22.0.400 process. That proves native conversion,
not a Karma beauty render. Export coordinates and units are preserved; API PLY
axis, metric scale and grounding normalization remain unverified. Full-resolution
performance, colliders, LODs and relinking are follow-up work.

## SideFX Markdown connection

`rag/ingest/sidefx_markdown.py` converts an explicit local snapshot manifest into
the existing flat Scout corpus schema. It accepts at most 16 pages per snapshot,
checks hashes and byte bounds, preserves source text and explicit anchors, and
publishes atomically only after every page validates. It performs no fetches,
model calls or scheduled work. APEX callback pages retain their existing
federated authority.

Each hit carries its source URL, hashes, docs build and document-only evidence.
Scout compares that build with the current runtime; docs do not grant runtime
symbol membership. Corpus freshness now observes subsecond file changes.

The local integration pilot imported Bake GSplats and SOP Import: two official
pages, 14 searchable rows. Its captured root index was 22.0.452, explicitly marked
ahead of the tested 22.0.400 runtime. Those downloaded pages and generated rows
are not bundled in this source release. Supply your own local snapshot using
the manifest schema in the importer's module documentation, then materialize it
through the existing Scout ingest path.

The wider docs library, staged guide serving, parameter/link graphs and nightly
refresh are not connected by this change. No new Jev runtime calls are added.

## Validation

- The release candidate's focused native panel suite passed 98 tests using
  Houdini 22.0.400's Qt. It includes repeated interactions, model selection,
  footer geometry, motion, stale-dialog cancellation and three isolated density
  probes.
- Source ownership, stylesheet and version checks passed 127 tests; 22 probes
  requiring Qt skipped in that separate stock-Python run. Release preparation
  moved model-picker label padding into its existing shared spacing owner and
  corrected the stylesheet guard's exact amendments for the already-approved
  composer and Send design. The spacing and stylesheet checks were red before
  these corrections, and deliberate border/focus mutations still fail.
- The World Labs client/native suite passed 29 tests, including degree-3 SH,
  repeated imports and cleanup that preserves a prior displayed import.
- Docs-related checks passed 73 tests; three optional dense-index tests skipped.
  A real two-page sample was retrieved through the existing Scout path.
- Deliberate mutations were rejected for stale deliveries, paid export payloads,
  missing rollback, missing provenance, bad page hashes, scope drift, freshness
  loss and destructive snapshot publication.
- The open Houdini session was updated and inspected. Before/after snapshots
  preserved the scene, conversations, drafts and selected model. A live-refresh
  compatibility fix was separately checked across four retained Qt class
  generations; it changes no release source or startup requirement.

These focused results do not assert that every local Windows test passed. The
previous broad Windows run had known and environment-related failures, recorded
in [v5.82.0](v5.82.0.md). Publication requires successful GitHub CI for the exact
release commit. Qt 5, unusual host themes, actual provider generation and the
remote World API are not qualified by these local checks.

**Known small-dock regression:** at 340 × 760 with 12px application text, the
wrapped inset controls and increased spacing leave less conversation area than
v5.82.0. With the input at its minimum, the three retained density profiles
measured 141/203/234px of transcript, versus 382/422/442px before these changes.
World Labs adds a fourth footer row at this width. The older 50%-of-panel
conversation assertions remain failing; they were not weakened. Use a wider or
taller dock for the intended open layout. A revised narrow-dock space budget is
follow-up work. Two additional legacy native assertions still assume a shorter
model tooltip and a configured API key; both conflicts already existed in
v5.82.0. None of these failures is included in the focused passing totals above.
