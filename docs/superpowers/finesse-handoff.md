# M6 panel finesse handoff

Commands retain their canonical identities through the catalogue and picker.
Events and Saved recipes open locally while idle or busy, keep the draft and
context, and leave focus with the selected dialog. Escape returns to the draft.
No-match feedback has a recovery button; reopening resets search and filters.
One cached popup per panel prevents an accumulating hidden-window population.

The footer uses native wrapping forms and a separate keyboard hint. Composer
and attachment controls have accessible names. Captions follow the selected
scale and use readable key names. Popup fitting accounts for native frame
margins after show-time growth; its deferred clamp timer belongs to the popup
and is cancelled with it.

The shelf selects the SYNAPSE interface at the first native creation call, for
both docked and floating paths. Default-then-switch had inherited Houdini's
QuickStartBrowser minimum of 862 pixels. The same final panel fits an actual
560-pixel-wide direct opening at the measured 2.25 scale. Existing tabs are
reused and docking remains preferred. The host toolbar is hidden by Houdini's
documented direct-interface behavior; existing tab geometry is not rewritten.

`harness/finesse-20260906/bus/receipts.jsonl`. The local dashboard references the
same checkpoint and includes complete-suite failures separately from the scoped
milestone verdict. Native review covers 197 assertions in 28 cases; the same
