# Retired agent definitions

Anything with a `name:` frontmatter under `.claude/agents/` is a live dispatch target: the Agent tool can invoke it, and its `tools:` line is runtime-enforced. This directory holds definitions pulled out of that roster because the harness they served is dead, so they are no longer registered as dispatch targets but their text survives for history and for the notes that cite it (`harness/notes/h22_compat_ledger.json`, `docs/sprint_freeze/marshal_map.md:510` still point at the old `.claude/agents/panel-relay/` paths; those are citations, not dispatches). `panel-relay/` (five definitions: `ls harness/retired/agents/panel-relay/*.md`) was retired 2026-09-15 by the harness review (`harness/notes/harness-review-2026-09-15/REPORT.md`, finding R2, part of R7): the PANEL RELAY harness is H21-era (first commit d06b72d6, 2026-06-02), `ASSAYER.md:3` targets Houdini 21.0.671, `ORCHESTRATOR.md:17,48` cite `shared/daemon` which does not exist in the tree, and `CRUCIBLE.md:4` held Edit, the only crucible with a write tool - yet all five were still registered. The runner scripts that drove them (`harness/retired/*.ps1`) were already retired. Nothing here is dispatched; do not move a definition back without re-verifying it against the current build.
