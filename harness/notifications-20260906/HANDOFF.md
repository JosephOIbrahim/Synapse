# M5: Know when the work is ready

SYNAPSE now has a session-local Events view for render, batch, model-connection
and explicitly watched Houdini work. Open Events under the prompt, or choose
`/events` in Commands. These entry points preserve the working draft and do not
dispatch a model. Desktop alerts are off by default; Quiet retains history
without issuing new alerts.

The journal is bounded to 200 records, has one process authority across panel
reloads, and keeps detached primitive facts. Render producers preserve their
existing result/exception contracts. Automatic legacy toasts now follow the
panel’s common policy; a suppressed alert cannot replay after opt-in. Desktop
messages are generic. Scene paths, model names and job details stay in Events.

Watch selected passively attaches to supported ROPs, File Cache outputs or an
existing TOP graph. It neither cooks nor initializes a graph. Foreground and
background cache registration are labeled separately. Native subscriptions stop
when their panel owner closes or the scene changes; Inspect validates the exact
scene generation and node session ID instead of jumping to a same-path replacement.

A TOP graph is Finished only after a bounded final inventory verifies cooked
nodes and terminal successful/cached items. A successful branch cannot hide a
pending or ungenerated sibling. ROP PostRender alone stays Needs attention because
it does not prove a complete requested range or cancellation outcome. Preview,
failure, cancellation and unknown observations remain distinct. None certifies
the contents of output files.

The Events view wraps controls at the host’s actual font scale, supports narrow
panels, keeps the footer reachable, and provides exact read-only details. Full
Houdini checks use an isolated 22.0.400 process, synthetic TOP work and a tiny
915-byte foreground cache. The artist’s installation and scene are unchanged.

Qualification and source hashes live in
`checks/notifications/qualification.json` in the refactor workspace. The final
local board copies the raw evidence and independent reviews; its receipt binds
the checkpoint. Earlier failures and corrected probe errors remain available.

Unqualified: real Windows alert delivery/history, background Save to Disk
execution, artist-driven Escape cancellation, long simulations, production
render integrity, external farms and other Houdini versions. Generic SOP range
completion is explicitly unsupported; use its cache output or TOP network.
The inherited wider-suite failures are recorded separately, not relabeled green.

Next authorized milestone: panel finesse. Use the measured 2.25-scale host and
actual narrow-panel interactions to improve control discovery, keyboard flow,
readability and consistent spacing. Preserve local memory/sharing language and
all existing scope, permission and lifetime behavior. Merge, release and
deployment remain outside this local checkpoint.
