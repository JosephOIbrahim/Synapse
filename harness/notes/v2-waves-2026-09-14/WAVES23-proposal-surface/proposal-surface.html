01Verdict

Two halves of one path. The machine half runs but does not guarantee what it claims; the human half is complete, styled, tested — and has never been reachable.

The machine half of the proposal path is built and has run — propose → validate → park → apply is real code with 57 instantiate_graph and 65 propose_graph provenance records already on disk (producer: python -c over .synapse/provenance/*.json, counting the op key; 5,000 of 5,001 files parsed — the 5,001st is a .tmp).
