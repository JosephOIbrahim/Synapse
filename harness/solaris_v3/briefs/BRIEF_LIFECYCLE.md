## Principle
A build is a transaction; a render is a job. Never hold a graph transaction open around a render. Failure recovery restores only what this run changed. `hou.undos.group()` **groups**; it does not roll back on exception (CLAUDE.md core guarantee) — a rollback is an explicit, measured act.
