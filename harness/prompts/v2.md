=== WHY THIS IS THE KEYSTONE, AND WHY IT MOVED UP ===

The blueprint moved this from Mile 7 to Mile 3 for one reason: **voice B — a register that holds constant across model swaps — is a dependency of frontier rotation.** Rotate the tier manifest without it and every rotation is a re-onboarding event, because the panel visibly becomes a different tool and trust was model-specific.

**E0 found a second reason nobody planned for, and it is the stronger one.**

```
E0-F5   the cache breakpoint wraps the WHOLE system prompt - and the prompt is NOT static
E0-F6   _solaris_context_block substring-matches the network path and APPENDS guidance,
        so the cached span changes the moment an artist navigates /stage -> /obj
system prompt, measured EXACT via count_tokens:  2,961 tokens, every turn
```

**Every cache write is paid at 1.25x and every read misses.** Invisible, because a cache miss looks exactly like normal operation.

**Here is the convergence.** §P7 says the register belongs to the panel, not the model: *the agent emits a structured object; the panel renders it.* If the model emits STRUCTURE instead of PROSE, the system prompt no longer needs to carry register instruction at all — **and register instruction is a large part of what makes that prompt non-static.**

So this leg does not just make voice consistent. **It shrinks the thing that cannot be cached.** Two problems, one contract.

=== WHAT YOU ARE BUILDING ===

**1. The verdict object.** Blueprint §3.1 gives the shape. Everything the Review face renders, emitted by the agent and drawn by the panel:

```
verdict   free text · ONE sentence · governed by the voice contract
decision  { chose, over, because }
via       { node_path, mechanism }
by        { model, tier, reason, tokens_in, tokens_out, cost }
checks    [ { state: ok | fail, text, ref } ]
paths     [ str ]
actions   [ { label, kind, forecast_tokens | null } ]
```

**`by` is the partner line and is NEVER null. A verdict with no author does not render.**

**2. The voice contract** — mechanically checkable rules on the single free field. One sentence. Outcome first, cause second. Names the thing that changed. No preamble, no hedging, no restating the request. A character ceiling.

**3. The validator.** Reject and re-ask on violation. **Three failures -> fall back to a verdict templated from `decision`.** A weak model must not be able to produce a weak panel.
