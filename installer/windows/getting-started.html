SYNAPSE is installed

Setup verifies runtime files, the panel and shelf definitions, icons, and Houdini registration. The following checks happen inside Houdini.

  1. Launch the Houdini installation and preference folder you selected.
  2. Choose New Pane Tab → Synapse. If it is under Python Panels, choose Synapse there. Enable the Synapse shelf if desired.
  3. Choose Doctor for live component diagnostics.
  4. Choose Connect models below the prompt. Select an engine and model, enter a key if required, then choose Check connection and Use this model. For Ollama, start its local service first.

Model access is separate from installation. Keys entered in the panel remain in that panel session. The separate Connect button controls the local Houdini bridge.

Verify, upgrade, or uninstall

Open Verify SYNAPSE installation from the Windows Start menu to check installed files. A file check cannot certify that Houdini loaded a package or that a model is reachable.

To upgrade, save and close Houdini, then run the newer Setup. To remove SYNAPSE, use Windows Settings → Apps → Installed apps → SYNAPSE → Uninstall.

Projects, memory stores, credentials, user settings and files you changed or added are preserved. If you migrated a source installation, uninstall restores its backed-up registrations; that older source installation may load again. An uninstall receipt and retained data may remain in the application folder.

Build status

This is an unsigned local review installer. Windows may warn about an unknown publisher. Code signing, public distribution and Moneta redistribution authorization are separate release steps. The tested target is Windows Houdini 22.0.400 with Python 3.13; other builds remain unverified.
